## 3. 关键差异说明

- **NewLife.Presto**：所有 ✅ 均有单测与真库（Trino 476 / PrestoDB 0.300）验证；事务、DDL、自增、存储过程明确不支持；EF 两个 Provider 只读，写入/迁移显式拒绝。
- **NReco.PrestoAdo**：无连接级 GetSchema；用户名缺失会抛异常；`ExecuteNonQuery` 固定返回 1；参数用 `{name}`；默认 `CheckInterval=1000 ms`，单次查询被拖到 2.5–3.6 秒（参测时调到 50 ms）。
- **PrestoClient**：REST SDK，无 ADO 表面；已知问题：状态枚举解析、未启用压缩、批量拉取未合并、`varbinary` 按十六进制解析。
- **Trino.Ado / Trino.Client.ADO**：连 PrestoDB 需显式 `ServerType=Presto`；均无 `DbProviderFactory`，只能直接 new 连接；未声明 AOT 支持。

## 4. 性能（Trino 476，同轮竞品对比，优化前数据）

| 指标 | NewLife.Presto | Trino.Ado | Trino.Client.ADO | NReco.PrestoAdo（CheckInterval=50） | 原始 HTTP |
|------|---:|---:|---:|---:|---:|
| 标量 `SELECT 1` | 35.8 ms | 30.3 ms | 29.8 ms | 261.0 ms | 17.0 ms |
| 聚合 15000 行 | 58.8 ms | 49.9 ms | 43.4 ms | 258.9 ms | 37.3 ms |
| 扫描 15000 行 | **76.4 ms** | 95.1 ms | 95.4 ms | 260.0 ms | 66.5 ms |
| 8 并发吞吐 | 46.8 次/秒 | **59.6 次/秒** | 45.3 次/秒 | 26.6 次/秒 | 53.4 次/秒 |
| 标量查询分配 | 156 KB | 97 KB | 95 KB | 90 KB | 16 KB |

优化后复测（本项目单独，同机同日）：Trino `SELECT 1` 12.5 ms、8 并发 128.9 次/秒；PrestoDB 22.2 ms、95.5 次/秒；分配 150/237 KB。详见 [性能测试](./性能测试.md)。

## 5. 结论

- 同赛道开源 ADO 驱动只有三个，其余高下载量包是 SDK、解析器或商业组件。
- 能力覆盖：本项目在 ADO 表面、认证、元数据、类型、ORM 上最全；唯一缺口是 Spooling（暂缓）。
- 性能：大结果集扫描最快；短查询与并发优化后领先；托管分配仍偏高，是下一阶段唯一优化项。
- 差异化：零第三方依赖、`net45`~`net11`、NativeAOT、XCode 默认集成、EF Core/EF6 只读 Provider。
