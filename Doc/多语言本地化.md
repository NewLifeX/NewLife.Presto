# 多语言本地化

> 基线：33 种运行时语言｜README 11 种语言｜英文为源文与兜底

## 1. 语言分层

本库对齐 NewLife 主流库的运行时语言规模，词表位于 `NewLife.Presto/Locales`，共 33 个文件（含显式 `en.yml`）：

```
ar bn cs da de el en es fa fi fr he hi hu id it ja ko ms nb nl pl pt ro ru sr sv th tr uk vi zh-Hans zh-Hant
```

- 文件名即 BCP 47 语言代码；`zh-Hans`/`zh-Hant` 分别承接简体与繁体区域文化。
- 英文是源文与兜底，`en.yml` 为工具对称保留，值等于键。
- 缺失译文在运行时自动回退英文；新增语言不需要改代码。

README 维护 11 种语言（见 `readme-languages.json`）：英文、简体中文、繁體中文、西班牙语、德语、日语、法语、葡萄牙语、俄语、韩语、阿拉伯语。

## 2. 词表格式

- 每行一条：`"English source": "译文"`，键必须与代码中的英文源文逐字一致（含空格与标点）。
- 占位符 `{0}` 与格式说明符必须与英文一致；翻译不得改变参数顺序。
- 文件为 UTF-8 无 BOM；`#` 开头为注释。
- 工具脚本要求所有语言文件键集合完全一致，缺键、多键、占位符不一致都会失败。

## 3. 代码约定

- 运行时异常消息：`throw new ArgumentException(Localization.Translate("Host cannot be empty."), nameof(Host));`
- 带参数：`Localization.Translate("Port must be between 1 and 65535.")`、`Localization.Translate("Command type {0} is not supported; use CommandType.Text.", type)`。
- 日志使用英文模板，由 NewLife.Core 日志器按当前文化翻译；不要把动态前缀拼进消息，否则整串无法命中词表。
- 服务器返回的错误原文保持原样；协议字段名、请求头名、ActivitySource 标签不翻译。
- 程序集 `AssemblyTitle`/`Description` 使用英文源文；展示层通过 `PrestoDriver.Title`/`Description` 取得译文。
- 词表由 NewLife.Core 源生成器在编译期读取 `AdditionalFiles`，写入程序集；NativeAOT 与裁剪场景同样可用。

## 4. 新增一条消息

1. 代码中写英文源文，使用 `Localization.Translate`。
2. 在全部 33 个语言文件的同一位置补齐该键（位置不限，键集合必须一致）。
3. 运行校验：

```powershell
pwsh -File tools/check-locales.ps1 -RequireTranslated
pwsh -File tools/report-locales.ps1 -RequireTranslated
pwsh -File tools/check-english-exceptions.ps1
pwsh -File tools/check-assembly-metadata.ps1
```

4. 单元测试 `LocalizationTests` 会逐语言验证译文非空、非英文占位、占位符可格式化。

## 5. 校验与 CI

| 脚本 | 作用 |
|------|------|
| `check-locales.ps1 -RequireTranslated` | 键集合、占位符、未翻译项、孤儿键、源码反向覆盖 |
| `report-locales.ps1 -RequireTranslated` | 每个语言的键数、缺失、未翻译统计 |
| `check-english-exceptions.ps1` | 运行时消息不得包含 CJK |
| `check-assembly-metadata.ps1` | 程序集标题/描述为英文且已入词表 |
| `check-config-metadata.ps1` | 配置类元数据英文 |
| `check-readme-coverage.ps1 -RequireFull` | 11 种 README 标题结构、代码块与表格一致 |
| `sync-readme-languages.ps1 -Check` | 语言切换行与配置一致 |
| `sync-readme-package.ps1 -Check` | `README.nuget.md` 与英文 README 一致 |
| `verify-localization.ps1` | 构建、测试与上述检查一键串联 |

CI 的 `localization` 作业与 `publish.yml`/`publish-beta.yml` 的发版门禁执行同一组脚本。

## 6. README 多语言

- `readme-languages.json` 是唯一事实源；数组顺序即展示顺序，前三固定为 English、简体中文、繁體中文。
- 语言切换行位于 `<!-- lang:start -->` 与 `<!-- lang:end -->` 之间，由脚本生成，禁止手改。
- 新增语种：先补 `README.xx.md`，再登记配置，最后运行 `sync-readme-languages.ps1`。
- 各版本必须保持与英文相同的标题层级、代码块内容与表格数量，`check-readme-coverage.ps1 -RequireFull` 会阻断摘要式翻译。

## 7. 不翻译范围

- BCL 参数异常等框架标准消息。
- 服务器返回的错误原文。
- 协议字段名、连接属性名、HTTP 头名、SQL 关键字。
- ActivitySource 名称与标签、结构化诊断字段（便于检索与工具解析）。
