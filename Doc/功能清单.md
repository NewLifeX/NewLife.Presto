## 拆分决策表

> 本项目为**纯后端 ADO.NET 类库**，无前端 UI、无 Web 管理后台；Presto/Trino 共用同一套协议实现，仅请求头前缀不同，不按平台拆分。以下仅记录可独立验证的拆分项。

| 需求项 | 原因 | 拆分结果 |
|--------|:----:|---------|
| 认证方式 | Basic、JWT 与 OAuth2 可独立验证 | SYS-5 基础认证 + SYS-6 JWT/Bearer 认证 + SYS-12 OAuth2 客户端凭据 |
| Presto/Trino 协议头 | 两套请求头可独立验证 | COMPAT-1 PrestoDB 协议头 + COMPAT-2 Trino 协议头 |
| 元数据集合 | Tables 与 Columns 可独立验证 | META-2 Tables + META-3 Columns |
| 批量执行 | 顺序提交与行数汇总可独立验证 | SQL-14 DbBatch |
| 复杂类型取值 | 结构化与字符串降级可独立验证 | SQL-15 复杂类型结构化 |
| 诊断接口 | 查询列表/详情与节点信息可独立验证 | META-9 查询诊断 API |
| ORM Provider | EF Core 与 EF6 的 API 与依赖完全不同，且各自独立发包 | EF-1~EF-6 EF Core Provider + EF-7~EF-8 EF6 Provider |
