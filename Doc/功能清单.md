## 拆分决策表

> 本项目为**纯后端 ADO.NET 类库**，无前端 UI、无 Web 管理后台；Presto/Trino 共用同一套协议实现，仅请求头前缀不同，不按平台拆分。以下仅记录可独立验证的拆分项。

| 需求项 | 原因 | 拆分结果 |
|--------|:----:|---------|
| 认证方式 | Basic 与 JWT 可独立验证 | SYS-5 基础认证 + SYS-6 JWT/Bearer 认证 |
| Presto/Trino 协议头 | 两套请求头可独立验证 | COMPAT-1 PrestoDB 协议头 + COMPAT-2 Trino 协议头 |
| 元数据集合 | Tables 与 Columns 可独立验证 | META-2 Tables + META-3 Columns |

| — | 复杂类型结构化对象 | 类型签名与对象模型复杂；先字符串降级 | 有明确复杂类型消费需求 |
