# NewLife.Presto 需求文档

> 版本：v2.1 | 日期：2026-11-21
> 完成状态见[功能清单](功能清单.md)，技术设计见[架构设计](架构设计.md)。

## 1. 定位

纯 C#、零第三方依赖的 Presto/Trino ADO.NET 驱动，面向 XCode 与 ADO.NET 应用，目标成为 XCode 中 Presto 的默认驱动；EF 支持以独立包提供。

| 工程 | 定位 |
|------|------|
| `NewLife.Presto` | 核心 ADO.NET 驱动（net45~net11，仅依赖 NewLife.Core） |
| `NewLife.Presto.EntityFrameworkCore` | EF Core 6/8/10/11 只读 Provider |
| `NewLife.Presto.EntityFramework` | EF 6 只读 Provider（net45/net461） |
| `UnitTest` / `UnitTest.EntityFrameworkCore` / `UnitTest.EntityFramework` | 离线单测、SQL 生成与真库集成 |
| `Test` / `AotSmoke` / `PerfTest` | 控制台冒烟、NativeAOT 冒烟、竞品性能基准 |

**非目标**：数据库服务端；事务提交/回滚；DDL 与自动迁移；自增主键；多语句；存储过程与游标；批量导入（BulkCopy）。

## 2. 模块

| 编号 | 模块 | 一句话 |
|------|------|--------|
| SYS | 系统基础 | 连接字符串、HTTP 传输、TLS、认证、会话、日志脱敏、AOT |
| PROTO | 协议与查询 | REST v1 语句生命周期、轮询、重试、错误、取消、压缩、Spooling 分段下载 |
| SQL | 查询执行 | Command/Reader/Parameter、`@` 替换、类型映射、CommandBehavior、批处理 |
| META | 元数据 | GetSchema、information_schema、服务端信息、查询诊断 |
| COMPAT | 兼容性 | 双协议头、版本与连接器差异、网关与代理 |
| I18N | 多语言 | 33 种运行时语言、11 种 README、CI 门禁 |
| XCODE | XCode 集成 | 工厂注册、连接串映射、参数化、能力边界 |
| EF | ORM 集成 | EF Core / EF6 只读 Provider（独立包） |
| QA | 质量与交付 | 单测、假 HTTP、真库集成、CI、打包、AOT 冒烟 |

## 3. 需求清单

### 3.1 SYS 系统基础

| 编号 | 需求 |
|------|------|
| SYS-1 | 连接字符串与别名：Host/Port/Catalog/Schema/User/Password、TLS、认证、会话、代理、压缩、Spooling、超时 |
| SYS-2 | 连接生命周期：Open/Close/Dispose/ChangeDatabase；默认 Open 不探测，`TestConnection` 才请求 `/v1/info` |
| SYS-3 | 共享 HttpClient：按端点 + TLS + 认证 + 代理缓存，复用底层连接 |
| SYS-4 | TLS：`UseSsl` 启用，默认严格校验；`TrustServerCertificate` 显式放宽并告警 |
| SYS-5 | Basic 认证：用户名缺省按环境用户、再退 `anonymous` |
| SYS-6 | JWT/Bearer：`Auth=JWT` + `AccessToken`，支持请求前刷新回调，令牌不入日志 |
| SYS-7 | 自定义请求头：适配网关/租户/追踪，禁止覆盖驱动核心头 |
| SYS-8 | 会话上下文：Catalog/Schema/User/Source/TimeZone/ClientTags/SessionProperties，处理服务端 Set-* 指令 |
| SYS-9 | 日志脱敏：不输出密码、令牌、完整连接串与查询文本 |
| SYS-10 | ActivitySource：Open/Execute/Fetch/Cancel 跨度，无订阅者零开销 |
| SYS-11 | NativeAOT：net8+ 裁剪零告警，编解码不使用运行时反射 |
| SYS-12 | OAuth2 客户端凭据：`client_credentials` + `expires_in` 提前刷新，回调优先；不做交互式登录 |

### 3.2 PROTO 协议与查询

| 编号 | 需求 |
|------|------|
| PROTO-1 | 语句提交：POST `/v1/statement`，携带会话头 |
| PROTO-2 | 轮询与状态机：按 `nextUri` 读取至缺失；状态按字符串保存，兼容未知状态 |
| PROTO-3 | 瞬态重试：429/502/503/504 按 `Retry-After` 或指数退避；只重试 GET/轮询，提交不重试 |
| PROTO-4 | 结果页解析：columns/data/stats/warnings，按页消费不累积整表 |
| PROTO-5 | 错误映射：message/errorCode/errorName/sqlState/failureInfo/errorLocation → `PrestoException` |
| PROTO-6 | 取消与超时：CTS + best-effort DELETE；取消异常不被清理异常覆盖 |
| PROTO-7 | 响应压缩：默认 `gzip, deflate`，可关闭 |
| PROTO-8 | 统计与警告：QueryId、耗时、行数/字节数、警告列表 |
| PROTO-9 | 服务端会话指令：Set-Catalog/Set-Schema/Set-Session/Clear-Session/Set-Role；不支持时告警不中断 |
| PROTO-10 | Spooling：`X-Trino-Query-Data-Encoding` 只声明未压缩 `json`；内嵌与对象存储分段按序拼接，读取后确认；不支持的编码或分段类型明确报错；服务端无该编码时自动回退直接协议 |

### 3.3 SQL 查询执行

| 编号 | 需求 |
|------|------|
| SQL-1 | 执行入口：ExecuteReader/Scalar/NonQuery 及异步；`CommandType` 仅 Text |
| SQL-2 | `@name` 替换：跳过字符串、标识符与注释；支持重复参数、检测缺失参数 |
| SQL-3 | 参数格式化：NULL/布尔/数值/字符串/日期/二进制/Guid/数组，字符串单引号转义 |
| SQL-4 | 标量类型映射：boolean~decimal、varchar/char/varbinary/json/uuid/ipaddress |
| SQL-5 | 日期时间映射：date/time/timestamp/tz/interval，保持精度与时区语义 |
| SQL-6 | 复杂类型降级：默认返回原始字符串，`GetFieldType` 为 String |
| SQL-7 | DataReader：Read/GetValue(s)/IsDBNull/GetFieldType/GetOrdinal/HasRows/RecordsAffected/Dispose |
| SQL-8 | GetSchemaTable：列名、序号、类型、可空性、基数 |
| SQL-9 | CommandBehavior：Default/SchemaOnly/SingleRow/CloseConnection |
| SQL-10 | ExecuteNonQuery 语义：updateCount → rows → -1，不伪造行数 |
| SQL-11 | 异步与取消：全链路 async/await + `ConfigureAwait(false)`，令牌贯穿提交/轮询/读取/清理 |
| SQL-12 | DataAdapter：只读 Fill；Update/Insert/Delete 不支持 |
| SQL-13 | DbDataSource（net8+）：`PrestoDataSource` 与 `CreateDataSource` |
| SQL-14 | DbBatch（net6+）：顺序逐条提交，执行汇总行数；不做服务端一次性批量 |
| SQL-15 | 复杂类型结构化：`ComplexTypes=Structured` 返回 Object[]/字典/Row，按签名递归转换 |

### 3.4 META 元数据

| 编号 | 需求 |
|------|------|
| META-1 | GetSchema 集合：MetaDataCollections/Tables/Columns/DataTypes |
| META-2 | Tables：`information_schema.tables`，支持 catalog/schema/table 过滤 |
| META-3 | Columns：`information_schema.columns`，含类型、可空、默认值 |
| META-4 | DataTypes：Presto/Trino 类型与 .NET 映射静态表 |
| META-5 | 服务端信息：`/v1/info`，仅在 TestConnection 或显式调用时请求 |
| META-6 | Catalog/Schema 发现：`SHOW CATALOGS`/`SHOW SCHEMAS`，短期缓存 |
| META-7 | 能力探测：按服务端类型与版本给出保守判断，不声称未验证能力 |
| META-8 | XCode 反向工程：information_schema 返回的类型、可空与排序可用 |
| META-9 | 查询诊断：只读 `GetQueries`/`GetQueryInfo`/`GetNodes`；不做 JMX/线程栈/终止查询 |

| 编号 | 需求 |

## 4. 暂缓与不做

| 项目 | 状态 | 原因 |
|------|------|------|
| Spooling 压缩编码（`json+lz4`/`json+zstd`）与真实对象存储集群验证 | 🧊 暂缓 | 零第三方依赖无法解码 LZ4/ZSTD；本机无对象存储测试环境 |
| OAuth2 交互式登录 | 🧊 暂缓 | 需浏览器/设备码交互；客户端凭据模式已支持 |
| JMX / 线程栈 / 集群管理 UI | 🧊 暂缓 | 运维接口不属于 ADO.NET 驱动；只读查询诊断已提供 |
| 服务端预编译语句 | 🧊 暂缓 | REST 无通用绑定参数，`PREPARE/EXECUTE` 受连接器限制 |
| riscv64 原生 CI | 🧊 暂缓 | 缺少稳定 runner 与 SDK |
| 事务 / DDL / 自增 / 多语句 / 存储过程 / BulkCopy | ❌ 不做 | Presto/Trino 协议与连接器不支持，驱动不模拟 |
